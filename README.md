# Raja Merak — Simulasi Edukasi Judi Online

Project pertama saya, dibuat tanpa pengetahuan coding sama sekali.
Menggunakan AI sebagai tools utama.

## Tujuan
Simulasi edukasi untuk awareness bahaya judi online.
Bukan platform judi — murni untuk menunjukkan bagaimana mekanisme 
judi online bekerja agar orang lebih aware dan tidak terjerumus.

## Catatan
Ini adalah dokumentasi perjalanan belajar saya dari titik nol.
Kode mungkin tidak terstruktur dengan baik — dan itu bagian dari ceritanya.
